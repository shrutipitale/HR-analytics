# 🏥 HealthStat – Healthcare Analytics Dashboard

An interactive healthcare analytics dashboard built using **Power BI** to analyze hospital performance, cost efficiency, and Length of Stay (LOS) trends across multiple health service areas.

---

## 📊 Project Overview

HealthStat provides comprehensive insights into:

- Average Length of Stay (LOS)
- Cost per discharge
- Hospital performance benchmarking
- Risk & severity-based discharge trends
- Cross-hospital cost comparison
- Patient disposition analysis

This dashboard helps healthcare stakeholders:
- Identify cost drivers
- Optimize hospital efficiency
- Monitor discharge trends
- Compare hospital performance across regions

---

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Modeling (Star Schema)
- KPI Dashboard Design
- Healthcare Dataset Analytics
